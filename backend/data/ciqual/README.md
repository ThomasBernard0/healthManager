# CIQUAL 2020

`ciqual-2020.tsv` holds energy and macros per 100 g for the 3 174 foods of the French food composition table
**Anses. 2020. Table de composition nutritionnelle des aliments Ciqual** (https://ciqual.anses.fr),
published under the [Licence Ouverte / Etalab](https://www.etalab.gouv.fr/licence-ouverte-open-licence).

Columns: `code` (alim_code), `name` (alim_nom_fr), `kcal` (const 328, else 333, else 4·P + 4·G + 9·L),
`protein` (25000), `carbs` (31000), `fat` (40000). `traces` and `< x` count as 0, a missing macro as 0.

- Generated by `convert.mjs` from the official XML export (see the header of that file).
- Loaded into `Food` (source `ciqual`) by `src/scripts/import-ciqual.ts`, which runs on every deploy before the
  app starts: new codes are inserted, existing ones are left alone (`--force` updates them).
